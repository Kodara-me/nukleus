# Manager icon

`nukleus-manager-master.png` was created with the built-in imagegen tool.
The Kira Canvas icon was a style reference. The committed PNG exports are build
inputs; no conversion tools are needed at build time or runtime.

Prompt: Create a production desktop application icon for Nukleus Manager.
Match the reference rounded dark navy square, luminous violet/lavender/blue
material and subtle depth. Replace the K with a simple three-tier server/model
stack with small status lights. No text or scene. Strong silhouette at small
sizes, centered square composition, transparent exterior.
